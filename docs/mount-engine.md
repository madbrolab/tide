# 挂载引擎 1.1.0

官方组件 ID：`mount`，提供 Linux amd64 和 arm64 发行包。组件按[云盘挂载插件](mount.md)的配置运行 FUSE 文件系统，支持目录缓存、数据块缓存、预读、限速、热更新和上传队列。

## 安装与运行

先安装云盘账号中心、所需连接器和云盘挂载插件，再从官方组件商店安装挂载引擎。基座须支持常驻组件；旧版基座请先升级。

云盘挂载插件启用时，基座自动启动已安装的引擎；插件停用或组件卸载时自动停止。异常退出按递增间隔重启，最长间隔 60 秒。正常停止会先卸载挂载点，最多留出 15 秒清理时间。

引擎经基座调用挂载插件，不直接接触账号凭据。挂载页的状态区显示运行情况、缓存和上传状态；管理员也可通过 `GET /api/v1/components/daemons` 查询进程状态。

## 容器要求

- 提供 `/dev/fuse` 设备与 `SYS_ADMIN` 能力；部分 NAS 还需要按系统要求调整 AppArmor 或 seccomp。
- 挂载 FUSE 的组件以 root 运行。
- 宿主机或其他容器需要看到挂载内容时，挂载点所在卷应配置 `rshared` 传播。
- 缓存和上传暂存目录应放在可写、容量足够的持久卷中，并与挂载点分开。

配置不足时，状态及日志会报告挂载失败，引擎随后重试。请先排查设备、权限和卷传播，再检查网盘账号。

## 缓存与写入

目录缓存区分常用目录、普通目录和不存在项；数据按块缓存，并按配置的容量、水位与淘汰策略回收。读取可预取后续块，网盘限流时采用退避。

写入默认关闭。开启条件、网盘差异和验证范围见[云盘挂载](mount.md#读取与写入)。上传队列可在重启后恢复；关闭容器前应查看待上传及失败任务，保留缓存和暂存卷。

这是由基座管理生命周期的常驻组件，没有可独立调用的动作，因此[组件动作契约](../store/interfaces/mount/operations.json)为空；业务接口由云盘挂载插件提供。

# tide.encrypted/1

开发者编写 JS，公开打包器加密，基座解密后编译并运行。公用加密材料随打包器提供，解密材料仅随基座保管。开发者及安装者均无需创建、上传或配置密钥。

ZIP 外层恰好包含两个文件：

| 文件 | 内容 |
| --- | --- |
| package.json | `format`、`algorithm`、封装后的 AES 密钥 |
| payload.enc | 12 字节 nonce、AES-GCM 密文及 16 字节认证标签 |

`format` 为 `tide.encrypted/1`，`algorithm` 为 `RSA-OAEP-SHA256+A256GCM`。每次打包随机生成 32 字节 AES 密钥及 nonce，使用 RSA-OAEP SHA-256、label `tide.encrypted/1` 封装密钥；package.json 原始 UTF-8 字节作为 AES-GCM AAD。不得在加密后重新格式化包头。

密文内部是压缩 ZIP，含清单、接口、图标、可选元数据、可选的 `console.mjs` 与 `console.css`、`release.json` 和 `unit-<entry>.js` 动作分片。发布描述绑定文件大小及 SHA-256，units 对应 JS 分片摘要；不接受开发者提供的可执行字节码。

基座核对格式、长度、解密认证、文件摘要、SDK、清单、动作、接口及依赖后，使用自身引擎编译分片并保存受保护的本地安装记录。运行时按动作加载缓存，不会为加密包增加 Python、Node.js、签名服务或常驻解密进程。重启不重复编译所有分片；引擎不兼容或缓存损坏会拒绝执行，需要重装兼容版本。

安装 ZIP 上限为 1 MiB，展开上限为 5 MiB；每个 JS 分片最多 256 KiB，最多 64 组、1024 个动作。较大的业务应拆分插件或采用分页、流式接口。

加密用于交付保护与完整性校验，不证明作者身份，也不保证本机管理员无法分析插件。来源由内置官方索引或用户启用的第三方仓库确定。旧签名格式保留兼容，新开发不需要沿用。

自定义页面设置清单 `console: true`，必须同时提供非空的脚本与样式，各最多 256 KiB；两个文件受同一加密与摘要检查保护。资源仅向管理员提供。详见 [自定义插件界面](console.md)。
